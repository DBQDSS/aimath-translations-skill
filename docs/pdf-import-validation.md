# PDF 导入验证记录

操作与诊断规则集中在 [PDF 配图规则](../references/pdf-figure-safety.md)，避免在文档中维护另一套规则。主入口见 [SKILL.md](../SKILL.md)。

每次验证可用下表记录；未执行的项标明“未验证”，不要用空白表示通过。

| 检查 | 应记录的证据与边界 |
|---|---|
| 源图定位 | 版本、物理页、裁剪坐标及旋转、最终印刷宽度 |
| 隐藏内容 | 抽取探针、对象/内容流检查；一次空提取不证明无隐藏内容 |
| 外观 | 源页直接渲染、独立图与最终PDF对比；小字、颜色、边界、公式 |
| 阅读器 | 名称与版本、选择状态、选择复制结果；未复现不宣称修复 |
| 栅格回退 | 直接源页、不透明RGB、像素尺寸、有效DPI；说明失去矢量缩放与可选标签 |
| 413离线分析 | 实际可得日志、总请求字节或估算依据；不推断图片是唯一原因 |
| 线上重试 | 实际响应结果；未调用服务必须明确说明 |

黑块先区分配图、公式、正文和选择覆盖层；更换配图不等于解决公式区域的选区黑块。生产图保留本地，小预览用于分批审阅，不能因此减少翻译覆盖范围。

可复用测试使用合成文档。私人源PDF、截图、案例名称、路径和生成结果留在项目测试目录，不进入分发仓库。
